# Sales Performance Dashboard — Power BI build guide

This folder contains the Power Query import script, DAX measures and a report blueprint. The source data is synthetic and is provided for portfolio demonstration only.

## 1. Load the data

1. Open Power BI Desktop.
2. Select **Transform data** → **New Source** → **Blank Query**.
3. Open **Advanced Editor**, replace its contents with `PowerQuery_Sales.m`, and select **Done**.
4. Rename the query to **Sales**.
5. Select **Close & Apply**.
6. In Model view, create a date table using the `Calendar` expression in `Sales_Measures.dax`, then create the one-to-many relationship from `Calendar[Date]` to `Sales[order_date]`.
7. Mark Calendar as the date table using `Calendar[Date]`.

If the GitHub raw data URL changes, replace it in the Power Query script.

## 2. Add measures

Create the measures in `Sales_Measures.dax` in the Sales table. The Calendar expression is a calculated table, not a measure. Apply currency formatting to revenue, cost, gross profit and average order value; apply percentage formatting to gross margin and average discount.

## 3. Report page layout

Set the page to 16:9 widescreen. Suggested title: **Sales Performance Overview**.

| Area | Visual | Fields |
|---|---|---|
| Top row | KPI cards | Total Revenue, Gross Profit, Gross Margin %, Orders, Units Sold |
| Upper left | Line chart | Calendar[Year Month] by Total Revenue; add Gross Profit as a second series if legible |
| Upper right | Clustered bar chart | Product by Total Revenue; sort descending |
| Lower left | Bar chart | Region by Total Revenue; tooltip: Gross Profit and Gross Margin % |
| Lower middle | Matrix | Category and Product rows; Total Revenue, Gross Profit, Gross Margin %, Units Sold |
| Lower right | Scatter chart | Average Discount % (X), Gross Margin % (Y), Total Revenue (size), Product (details/legend) |

Add slicers for Calendar[Year], Region, Category and Product. Use single-select only where it improves the question being answered. Enable useful tooltips and data labels without overcrowding the page.

## 4. Analytical questions to surface

- Is revenue growth accompanied by gross-profit growth?
- Which products contribute the most revenue and which deliver the strongest margins?
- Does regional revenue leadership also translate into profit contribution?
- Are higher discounts associated with lower gross margins?
- Are there months with unusually weak revenue or gross profit?

## 5. Validation before publishing

- Confirm the imported row count is 900 and order IDs are distinct.
- Reconcile Total Revenue to approximately **GHS 8,389,891.74** and Laptop revenue to approximately **GHS 3,487,963.36**.
- Reconcile Kumasi revenue to approximately **GHS 2,159,211.18**.
- Check that date and region/category/product slicers filter every relevant visual.
- Check gross margin is calculated as total gross profit divided by total revenue, not as an average of row-level margins.
- Inspect negative gross-profit transactions rather than deleting them automatically.
- Test the report at normal laptop screen size and ensure titles, units and labels are readable.

## 6. Publish

Save the finished report as `Sales_Performance_Dashboard.pbix`. Publish through Power BI Desktop to a workspace you are authorized to use. Only publish the PBIX after completing the validation steps above.

**Important:** This repository provides the reproducible source query, measures and build specification. A Power BI Desktop `.pbix` file is not generated by these source files; you must build and save the report in Power BI Desktop.
